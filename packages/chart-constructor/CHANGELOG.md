# react-chart-constructor

## 1.0.0

首个正式版本：基于 React 与 ECharts 的图表构造器组件库，支持配置项编辑、实时预览与配置导出。

### 图表类型

- 新增柱状图（`bar`），并将 `ChartConfig` / `ChartData` / `ChartSettings` 改造为按图表类型区分的联合类型
- 新增折线图（`line`）、散点图（`scatter`）与折线柱状图（`combo`）：折线图复用分类序列并支持平滑曲线、面积填充与数据点开关；散点图使用数值 x/y 坐标并以数值轴渲染 X 轴；折线柱状图每个系列可切换柱状/折线并共用单 Y 轴
- 抽出直角坐标系网格与坐标轴共享构建器，供各图表复用
- 新增 `listChartMetas` 与 `getChartMeta` 公共导出及 `ChartMeta` 类型，便于按注册顺序枚举内置图表类型

### 主题

- 新增全局主题注册入口：导出 `registerTheme` 包装 `echarts.registerTheme`，导出 `setDefaultTheme` / `getDefaultTheme` 维护全局默认主题
- 未显式传入 `theme` 的图表自动套用全局默认主题，运行期切换主题时同步重建；新增 `ChartTheme` 类型，主题不进入 `ChartConfig`

### 编辑抽屉

- 抽屉顶部内嵌实时预览图（只渲染图表本身，不挂操作栏）；配置状态拆为「草稿 / 已提交」两层，点编辑取当时快照，编辑只改草稿，点保存才提交并输出
- `onChange` 语义改为「保存时输出」（草稿与已提交值一致时不触发），`onSave` 仍在点击保存时触发
- 配置表单新增分组 tab：按「数据 / 标注 / 其他」切换，无对应表单块的空分组自动隐藏，tab 栏在表单区滚动时吸顶
- 抽屉加宽为 960 并改为「左侧实时预览 + 右侧配置表单」左右布局，窄屏（≤900px）占满视口并回退上下堆叠

### 操作栏

- 新增 `toolbarMode` 配置项（`static` / `float`）：默认 `static` 保持操作栏常驻图表上方；`float` 时操作栏脱离文档流悬浮在图表右上角，悬停淡入、移出淡出，触屏设备自动回退为常显悬浮角标
- `ToolItem` 新增可选 `tooltip` 字段：悬停展示提示文案并自动补全 `aria-label`，便于把操作栏做成纯图标按钮

### 坐标轴

- X 轴新增轴名称位置配置项（起点 / 居中 / 末端，默认末端），并按位置自动预留网格留白，修复轴名称被画布右边缘裁掉的问题
